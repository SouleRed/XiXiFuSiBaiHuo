# 章节地图与接待图标（LS_InvitationUtil）

关卡数量多时用 `ChapterMap` 组织：一张独立主线地图，内部按 `Grade` 分小节，每个接待作为图标挂在对应 `Grade` 上。

## 文件位置

| 内容 | 路径 |
|---|---|
| 章节地图 | `MOD根目录\Data\XmlInfos\ChapterMap\ChapterMap.xml` |
| 接待图标 | `MOD根目录\Data\XmlInfos\StoryIcon\StoryIcon.xml` |
| 图标图片 | `MOD根目录\Resource\AssetFiles\Artworks\<名字>.png` |
| 章节/小节标题文本 | `MOD根目录\Assemblies\Localize\cn\etc\*.xml` |

## 一张地图 + 多个 Grade

```xml
<ChapterMapXmlRoot>
  <Version>1.1</Version>
  <ChapterMap ID="1">
    <Name>CFK_ChapterMap</Name>
    <Chapter>7</Chapter>                 <!-- 玩家章节达到该值才显示 -->
    <Condition><Level>0</Level></Condition>
    <Grade Name="0">                     <!-- 小节，按出现顺序从 0 编号 -->
      <Icon>CFK_ChapterIcon</Icon>       <!-- Artworks 下的资源名（去扩展名） -->
      <Title>ui_cfk_chapter_0</Title>    <!-- 文本 ID -->
      <Condition><Level>0</Level></Condition>
      <Story>CFK_StoryIcon_0</Story>     <!-- 引用 MapIconSlot 的 Name -->
      <RectSize>0.75</RectSize>          <!-- 选中时地图缩放 -->
      <Position x="0" y="0" />
      <Line RequireFinish="true" x="0" y="0" w="120" h="4">90</Line>
    </Grade>
  </ChapterMap>
</ChapterMapXmlRoot>
```

- 新增关卡：**加 Grade**（图标/标题/条件/位置），不需要新建地图
- `Grade` 之间的连线写在 Grade 的 `Line` 里，`w` 长度、`h` 粗细、元素文本是旋转角度

## 每个接待一个 MapIconSlot

```xml
<StoryIconRoot>
  <Version>1.1</Version>
  <MapIconSlot ID="1">
    <Name>CFK_StoryIcon_0</Name>          <!-- Grade 的 Story 引用这个 -->
    <RequireUnlock>true</RequireUnlock>   <!-- 未通关时显示锁定态 -->
    <Stage Pid="CaiFengKing">1</Stage>    <!-- 本模组关卡 ID -->
    <Position x="0" y="0" />
    <ChapterMap>1</ChapterMap>            <!-- 属于哪张章节地图 -->
    <Grade>0</Grade>                      <!-- 落在第几级，从 0 开始 -->
  </MapIconSlot>
</StoryIconRoot>
```

多个接待可在同一个 `MapIconSlot` 的 `Stage` 里写多个 ID（任一可玩即显示图标）。

## 原版主线图标（不用 ChapterMap 时）

```xml
<IconSlot ID="1">
  <Name>CFK_StoryIcon</Name>
  <Stage Pid="CaiFengKing">1</Stage>
  <Position x="0" y="120" />
  <Line RequireFinish="true" x="0" y="0" w="120" h="4">90</Line>
  <Locate>Rats</Locate>     <!-- 以原版哪个接待为锚点 -->
  <Turn>false</Turn>
</IconSlot>
```

`IconSlot` 没有 Icon 字段，图形来自插件内置共享图标包；需要自定义图案时走 `ChapterMap` + `Grade/Icon`。

## 文案约定

- 标题/文本写进 `Assemblies\Localize\cn\etc\*.xml`，根节点 `localize`，`<text id="...">内容</text>`
- 禁止全角中文标点

## 排错

| 现象 | 检查 |
|---|---|
| 地图不出现 | `Chapter` 是否高于玩家当前章节；`Condition/Level` 是否满足 |
| 地图出现但没图标 | `Grade/Story` 与 `MapIconSlot/Name` 是否一致；`ChapterMap`/`Grade` 编号是否对应 |
| 图标空白 | 图片是否在 `Resource\AssetFiles\Artworks`，资源名是否与文件名（去扩展名）完全一致、大小写一致 |
| 文本显示键名 | `Assemblies\Localize\cn\etc` 下是否缺该 ID 的 `text` 节点 |
| 整体不生效 | 日志 `Error while load mod`；确认 `Assemblies\1FrameworkAssemblies\LS_InvitationUtil.dll` 存在且版本支持 |

## 与 BaseMod 布局的关系

本项目的关卡仍由 BaseMod 从 `StaticInfo\StageInfo\StageInfo.xml` 注册；
`Data\XmlInfos` 只承载框架扩展（章节地图、图标等）。两者用同一个关卡 ID 关联：
`MapIconSlot/Stage` 写 `Pid="CaiFengKing"` + 关卡 ID。

## 已知问题：2.0.0.0 的 ChapterMap 反序列化失败

现象：`ChapterMap.xml` 完全不加载，日志报

```
Error while load "ChapterMap" xml file from "<模组ID>"
System.InvalidOperationException: There was an error reflecting type 'ChapterMapXmlRoot'
  -> field 'condition' -> type 'StageExtraCondition_Overrides'
  -> field 'NeedClearStages_Overrides'
  -> The XML element 'Stage' from namespace '' is already present in the current scope.
```

机制：`StageExtraCondition_Overrides.NeedClearStages_Overrides` 的 `XmlElement("Stage")`
与基类 `StageExtraCondition` 的 `Stage` 元素重名，`XmlSerializer` 在**反射建图阶段**就抛异常，
所以只要 `<Condition>` 类型被引用，整个 ChapterMap 文件都读不进来（与 XML 内容无关）。

本地临时处理：用 Cecil 把该字段的 `XmlElement` 名改成 `NeedClearStage`（不改逻辑，只是让序列化器能建图）。
- 补丁脚本思路：读 `LS_InvitationUtil.dll` → 找 `LS_InvitationUtil.XML.Overrides.StageExtraCondition_Overrides.NeedClearStages_Overrides`
  → 替换其 `XmlElementAttribute` 构造参数 → 重新写出
- 副作用：条件里不再能写 `<NeedClearStage>` 之外的新语义；原有 `<Stage>` 条件仍由基类处理
- **作者修复后应换回官方 dll**，不要长期维护补丁
## 没有剧情的 MOD 不要写 Story 节点

`StaticInfo\StageInfo\StageInfo.xml` 里如果留了 `<Story Condition="Start"/>`、`<Story Condition="End"/>` 或 `<StoryType>`，
游戏会认为该接待有剧情，从而在剧情线/章节地图上**额外生成一个剧情图标**；关卡图标与剧情图标重叠时，
点到的很可能是剧情图标，触发 `StoryScene.StoryManager` 播放原版剧情。

实测崩溃：

```
IndexOutOfRangeException
  at UI.UIStoryProgressIconSlot.SetLevelUIColor (Color c, Int32 level)
  at UI.UIStoryProgressIconSlot.<OnClickStoryButton>b__73_0 ()
  at StoryScene.StoryRoot.EndStory (Boolean forcely)
```

`SetLevelUIColor` 用章节值当颜色数组下标；第七章（7）超出原版 0~6 的范围，所以越界。
本项目无剧情，处理方式：**删掉全部 `<Story>` 与 `<StoryType>` 节点**，只保留 `<Chapter>7</Chapter>`。
## 引用原版书籍必须写 Pid="@origin"

`Invitation` 的 `<Book>` 引用**原版**书页时，必须显式写 `Pid="@origin"`：

```xml
<Invitation Combine="BookRecipe">
  <Book Pid="@origin">250034</Book>
  <Book Pid="@origin">250035</Book>
  <Book Pid="@origin">250037</Book>
</Invitation>
```

不写 `Pid` 会被解析成**本模组的书**，找不到就退化成"棍木"这类占位书页，表现为邀请函里显示错误的书、或无法发送邀请。

引用本模组自己的书页则写包名：

```xml
<Book Pid="CaiFengKing">1</Book>
```
