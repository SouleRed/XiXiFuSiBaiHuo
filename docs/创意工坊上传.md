## 日常用法

```powershell
# 构建 + 上传（更新说明会写入 5 语言）
.\Upload-Workshop.ps1 -ChangeNote "修复预览插件"

# 只校验不上传
.\Upload-Workshop.ps1 -DryRun

# 只更新页面文案，不动内容
.\Upload-Workshop.ps1 -PageOnly -IncludeDescription

# 跳过构建，直接传现有 MOD根目录
.\Upload-Workshop.ps1 -SkipBuild -ChangeNote "仅资源"
```

脚本内部流程：`BuildAndDeploy.ps1` → `configure` → `inspect` → `publish --confirm`。

## 草稿文件

`workshop.draft.json` 是**唯一的文案来源**，5 种语言各一份：

```json
{
  "workshopId": 3846266202,
  "lastContentLanguage": "schinese",
  "pageOnly": false,
  "includeDescription": true,
  "visibility": "Keep",
  "tags": ["invitation"],
  "copies": [
    { "language": "schinese", "title": "...", "description": "...", "changeLog": "" },
    { "language": "tchinese", ... },
    { "language": "english", ... },
    { "language": "japanese", ... },
    { "language": "koreana", ... }
  ]
}
```

- 语言代码固定为 `schinese` / `tchinese` / `english` / `japanese` / `koreana`
- 描述支持 Steam BBCode（`[h1]`、`[b]`、`[list]` 等）
- 限制：标题 ≤128 字符，简介 ≤8000，更新说明 ≤8000，封面 <1 MB

## 直接调用工具

```powershell
$exe = "C:\Users\MECHREVO\OneDrive\废墟图书馆mod工程文件\SteamworkUploader.exe"

# 查看 CLI 说明
& $exe guide

# 记忆的项目 / 检查目录
& $exe list
& $exe inspect --folder "MOD根目录"

# 从工坊拉取现有 5 语言文案
& $exe fetch --id 3846266202 --out workshop.draft.json

# 写入草稿
& $exe configure --folder "MOD根目录" --json workshop.draft.json

# 试运行 / 发布
& $exe publish --folder "MOD根目录" --dry-run
& $exe publish --folder "MOD根目录" --confirm --visibility Keep
```

## 与旧工具的区别

| | 旧 GUI/自建 CLI | 新工具 |
|---|---|---|
| 多语言描述 | 接口只能写基础语言 | **5 语言各自独立**（`copies[]`） |
| 发布前校验 | 无 | `publish --dry-run` 输出计划 |
| 读取现有文案 | 只能拿默认语言 | `fetch` 拉全部 5 语言 |
| 配置存储 | 项目内 JSON | 工具记忆 + 项目内草稿 |

## 常见问题

| 现象 | 处理 |
|---|---|
| `Project not found in history` | 先跑 `configure`（我们的脚本已自动做） |
| PowerShell 中文乱码 | 调用前设置 `[Console]::OutputEncoding = [Text.UTF8Encoding]::new($false)` |
| 首次发布需要同意协议 | 打开返回的链接在网页同意 |
| 标题/简介被改 | 检查 `workshop.draft.json` 的 `copies`，`publish` 会按草稿覆盖 |
