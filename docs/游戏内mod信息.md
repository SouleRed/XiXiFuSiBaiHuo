# 游戏内 Mod 信息（StageModInfo.xml）

游戏内 Mod 列表显示的是 `MOD根目录\StageModInfo.xml` 的 `<Title>` 与 `<Description>`。
这里用 `/` 把四种语言串在一起，顺序固定为：

```
中文 / English / 한국어 / 日本語
```

修改任何语言时，**四个位置必须同时保持这个顺序**，否则会串位。

```

接待位置目前在扭曲阳左边/The reception is currently located to the left of Distorted Yang./접대 위치는 현재 뒤틀린 양 왼쪽에 있습니다./接待の位置は現在、歪んだ陽の左側にあります。
```
